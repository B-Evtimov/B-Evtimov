### 🔭 What I'm building

- **📡 Wi-Fi 3D Human Tracking (CSI)** — tracking people through walls using only Wi-Fi signals. 8 ESP32 receiver nodes, 3-camera MediaPipe ground truth, HDF5 dataset pipeline, a custom PyTorch model (`CsiPoseNet`) and live radar-style inference.
- **🚪 Doors Control System** — phone-only access control: Android app + FastAPI + PostgreSQL + ESP32 door controllers. Threat-modelled architecture, Ed25519 challenge-response for the controllers, append-only hash-chained audit log, rootless containers.
- **☁️ Personal Cloud** — self-hosted file storage with end-to-end encryption. The server only ever sees encrypted blobs. Node.js backend + React Native (Expo) app, exposed through Cloudflare Tunnel & Tailscale.
- **🏫 School OS** — building automation for a real school: ESP8266 nodes, MQTT, FastAPI and scheduled lighting, with Wi-Fi-CSI occupancy detection in V2.
- **📄 School Docs AI** — an AI assistant for school paperwork: document generation from templates, RAG over Bulgarian education law with source citations, validation of required fields.
